Package Armor v1.0.0

An advanced Flutter Linux desktop application for comprehensive package installation and management

Installation:
  sudo ./install.sh    # System-wide installation
  ./install.sh         # User installation

Uninstallation:
  sudo ./uninstall.sh  # System-wide removal
  ./uninstall.sh       # User removal

Running:
  package-armor

For more information, visit: https://github.com/Piyu-Pika/linux_package_manager
